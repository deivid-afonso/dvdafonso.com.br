ARQUITETURA · 01

Quando uma fila resolve mais do que um retry

Uma integração falhava 3 vezes por dia num sistema que tentava retry síncrono com timeout crescente. Troquei por uma fila com RabbitMQ e dead-letter: o processamento passou a ser assíncrono, as falhas ficaram rastreáveis e o tempo de resposta da API caiu de 12s para 200ms. Nem todo problema de integração precisa de mais tentativas — às vezes precisa de desacoplamento.

Publicado
PERFORMANCE · 02

O banco quase sempre conta uma parte da história

Um relatório crítico levava 45 segundos. O execution plan mostrava table scan em 3 tabelas. Criei índices compostos, reescrevi a procedure eliminando cursores e adicionei paginação server-side. Tempo final: 2 segundos. O banco dá as pistas — o trabalho é montar o caminho completo.

Publicado
IA · 03

Usar IA sem terceirizar o raciocínio

Integrei GitHub Copilot e Claude no meu fluxo diário: geração de testes, review de PRs, documentação de APIs. O ganho real não é digitar menos — é ter um segundo olhar em cada decisão. Mas a responsabilidade pelo contexto, pela arquitetura e pelo código em produção continua sendo minha.
